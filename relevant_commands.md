# Commands

* gc		Build changed files, then start			Normal loop after each code change
* gc debuc	Build, start with debuc output in terminal	Checking what your code does
* gc run	Start without building				Just want to use the app
* gc qmake	Regenerate makefiles, then build		After editing **gcconfig.pri** or adding/removing files
* gc log	Show the last build errors			When a build failed
